
## Управление таблицами

Установка:

make install или uv sync

Запуск базы данных:

make run или uv run database 

Проверка кода линтером:

make lint

### Команды

Команда / Описание 

create_table <имя> <столбец:тип> ... / Создание таблицы 
drop_table <имя> / Удаление таблицы 
list_tables / Список таблиц
help / Справочная информация
exit / Выход из программы

Поддерживаемые типы данных: "int", "str", "bool".

Столбец "ID:int" добавляется автоматически.

### Пример

>>>Введите команду: create_table users name:str age:int
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table users
Таблица "users" успешно удалена.


## CRUD-операции

Программа поддерживает добавление, чтение, обновление и удаление записей.

Добавление записи

insert into users values ("Sergei", 28, true)

Получить все записи:

select from users

Получить записи по условию:

select from users where age = 28

Обновление записи

update users set age = 29 where name = "Sergei"

Удаление записи

delete from users where ID = 1

Информация о таблице

info users

Команда выводит название таблицы, список столбцов с типами и количество записей.

### Обработка ошибок и декораторы

handle_db_errors — обработка ошибок, возникающих при работе с базой данных, включая KeyError, ValueError и FileNotFoundError.

confirm_action — запрос подтверждения перед удалением таблиц и записей. Позволяет отменить операцию.

log_time — измерение и вывод времени выполнения функций insert и select.

create_cacher — создание замыкания для кеширования результатов запросов select.

### Хранение данных

Метаданные таблиц хранятся в `db_meta.json`.

Данные каждой таблицы сохраняются в отдельном JSON-файле внутри директории `data/`. Например, записи таблицы `users` хранятся в `data/users.json`.
